# VectorFlow: Multi-Agent 2D Asset Engine

VectorFlow is a production-hardened AI system designed for indie game developers. It transforms natural language
descriptions into clean, scalable, and stylistically consistent SVG assets through a state-managed multi-agent pipeline.

---

## Agent Architecture

Pattern: Peer / Pipeline (Sequential Handoff)

Justification: We separate Creative Direction from SVG Implementation. The Creative Director agent (Gemini 3.1 Flash Lite)
brainstorms aesthetic details, while the Artist agent (Gemini 2.0 Flash or Claude 4.6) focuses purely on XML syntax.
This prevents conversational text from leaking into code blocks and ensures aesthetic decisions are finalized before coding begins.

### AgentState Definition

| Field          | Type    | Description                                |
|:---------------|:--------|:-------------------------------------------|
| session_id     | string  | UUID for conversation memory               |
| user_request   | string  | The raw user prompt                        |
| style_context  | string  | The Style Locker setting (e.g., Cyberpunk) |
| creative_brief | string  | Textual art direction generated by Node 1  |
| final_response | string  | The final cleaned SVG XML code             |
| use_pro_model  | boolean | Flag to trigger the safety gate            |
| approved       | boolean | Human-in-the-loop approval status          |
| retry_count    | integer | Resilience tracking for audit purposes     |

### Irreversible Actions

Action: Invoking Pro Model (Claude 4.6 Sonnet).
Guard: The route_safety node in our orchestrator acts as a Human Approval Gate. It halts execution and requires an
explicit approved=True flag in the state before proceeding to high-cost models.

## Safety and Resilience

1. Irreversible Actions: Calling the Pro Model (Claude 4.6) is guarded by a manual approved flag in the state machine to prevent credit exhaustion.
2. Fallback Chain: We implement a 3-tier loop (Primary -> Secondary -> OSS). Verified to failover in under 500ms during provider downtime.
3. Rate Limiting: Enforced at 10 requests per minute per user. Rejects spam with a structured 429 JSON response.
4. Input Sanitization: User input is treated as data and wrapped in protocol delimiters to prevent prompt injection.

## Setup and Execution

### 1. Environment Setup
The project requires Python 3.14 or higher.

    python -m venv .venv
    .venv\Scripts\activate
    pip install fastapi uvicorn openai streamlit python-dotenv mcp langgraph pandas httpx locust

    uvicorn main:app --reload

    python mcp-server/server.py

## Data Governance

1. Isolation: Users are strictly isolated by unique session UUIDs. Cross-user data retrieval is prevented at the session service layer.
2. PII Policy: All persistent logs (CSV/JSONL) use a hashed version of user prompts to ensure zero storage of personally identifiable information.
3. Retention: Conversation history is kept in-memory and cleared upon session reset or server restart.
